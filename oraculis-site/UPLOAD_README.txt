LAST ORIZON – GITHUB PAGES STRUCTURE

Repository: orizon

Upload the contents of this folder to the ROOT of your GitHub repository.

Final structure:

index.html          <- landing page
de/index.html       <- German Twine game
en/index.html       <- English Twine game

Important:
- The root index.html must stay in the repository root.
- The German game must stay inside the folder "de".
- The English game must stay inside the folder "en".
- GitHub Pages may take a minute or two to update after each commit.

Landing page links:
./de/   German game
./en/   English game

With a repository named "orizon", the public URLs will normally be:
https://YOUR-USERNAME.github.io/orizon/
https://YOUR-USERNAME.github.io/orizon/de/
https://YOUR-USERNAME.github.io/orizon/en/
